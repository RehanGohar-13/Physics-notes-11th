Case-II : Pipe Is Closed From One Side
When the pipe of length "l" is closed from one end. Closed Ends behave as nodes because Air molecules don't have enough freedom to move.
A — 1st Mode of Vibration :
★ Board note: In this Case We have one node and one anti-node.
l = λ₁ / 4
{ 4l = λ₁ }
As we know:
v = f₁ λ₁
v / λ₁ = f₁
{ v / 4l = f₁ }  ∵ [λ₁ = 4l]
B — 2nd Mode of Vibration :
l = λ₂/4 + λ₂/2

Base dimensions · Calculation by base units
Dimensions of Base Quantities Symbols
Mass [M] Temperature [θ] Electric current [I] / [A] Amount of substance [N] Intensity of light [J]

(Also from earlier page: Length [L], Time [T])

Calculation of Dimensions
a • By using Base units.
EXAMPLE
Calculate the dimension of velocity.
v = ms⁻¹ ∵ m → [L]  |  s → [T]
v = [L][T]⁻¹
v = [LT⁻¹]
Notebook side note: wrote “m = mass = [L]”.
In SI unit string ms⁻¹, m = metre = Length [L], and s = second = Time [T]. Mass would be kg → [M]. Final answer [LT⁻¹] is correct.
EXAMPLE
Calculate the dimension of acceleration.
a = ms⁻²
a = [L][T]⁻²
a = [LT⁻²]
Quick board strip
velocity      v = ms⁻¹   →   [LT⁻¹]

Stationary Waves In Stretched String
College notes · One long derivation (3 physical pages combined) · Harmonics on a string
Setup (board):
Consider a string of Length l clamped by both ends.
F is force by tension.

Wave speed on string:  v = √(F / m)   where m = mass per unit length
Board spelling “Streched” → Stretched. Ends fixed = nodes at both ends.
A · Plucked from centre
Fundamental mode (1st harmonic):
N — node · A — antinode · single loop between ends
String is Plucked from centre, two transverse waves travelling in opposite direction Combine and give rise to standing waves.
Distance b/w two consecutive nodes are half of wavelength.

l = λ₁ / 2
( 2l = λ₁ )

As we know,   f₁ λ₁ = v
f₁ = v / λ₁
f₁ = v / (2l)   …… (i)   [∵ λ₁ = 2l]

We know v = √(F / m)

From Eq (i):
f₁ = (1 / 2l) √(F / m)
This is the fundamental frequency (1st harmonic). Lowest possible frequency for the string.
B · Plucked from quarter length
Second harmonic (two loops):
Now string is vibrating two loops (2 antinodes, 3 nodes)
l = λ₂/2 + λ₂/2 = λ₂
l = λ₂

Again: f₂ λ₂ = v
f₂ = v / λ₂
f₂ = v / l    [∵ λ₂ = l]

Multiply and Divide by "2":
f₂ = 2v / (2l) = 2 (v / 2l)
f₂ = 2 f₁    [∵ f₁ = v / 2l]
C · Plucked from arbitrary length
General / nth harmonic:
String is plucked from arbitrary Length. It vibrates in "n" Antinode (Loop) and "n+1" nodes. So,

( λₙ = 2l / n )

and

( fₙ = n f₁ )    [∵ f₁ = v / 2l]
Master result (exam box):
f₁ = (1 / 2l) √(F / m)

fₙ = n / (2l) · √(F / m) = n f₁

n = 1, 2, 3, …  |  n = 1 fundamental  |  n = 2 octave / 2nd harmonic
Board Check: Teacher’s m = linear density (often written μ in textbooks). Fixed–fixed string → only integer harmonics (no even/odd restriction like open organ pipes). Wavelength fit: length holds n half-wavelengths → L = n (λ/2) → λ = 2L/n.

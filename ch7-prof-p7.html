Interference of wave
Absent Day 2 · Experimental setup · Constructive
Definition (board):
Type of superposition in which waves of same frequency and traveling in same direction overlaps.
Experimental setup :-
  1. A.G (Audio Generator)
  2. P.A (Power Amplifier)
  3. S₁, S₂ (Speakers)
  4. Sensitive microphones
  5. C.R.O (Cathode ray oscilloscope) — it convert input signals into graph
Diagram :-
Green rings = S₁ · Red rings = S₂ · P₁…P₅ = intersection / observation points (board diagram).
Constructive interference :-
Type of interference in which crest lies on crest and trough lies on trough. In this way displacement / Amplitude increases.

ΔS = nλ
(ΔS space between waves) (λ wavelength) (n integers)

In this case Path differen (ΔS) is integral (n) multiple of wavelength (λ).
Board Check: n = 0, 1, 2, 3… → path difference is whole number of wavelengths → bright / loud.

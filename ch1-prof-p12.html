Deriving a Formula · Centripetal Force
Deriving a Formula:

The formula for centripetal force is derived based on the following factors:

  • mass (m)
  • velocity (v)
  • Radius of circle (r)
Solution:
F ∝ mᵃ vᵇ rᶜ
F = [constant] mᵃ vᵇ rᶜ   ————— (i)

Using dimensions :-
[MLT⁻²] = (constant) [Mᵃ] [LT⁻¹]ᵇ [Lᶜ]
[MLT⁻²] = (constant) [Mᵃ] [Lᵇ] [T⁻ᵇ] [Lᶜ]
[MLT⁻²] = (Constant) [Mᵃ] [Lᵇ⁺ᶜ] [T⁻ᵇ]
By comparing power:-
⇒ M
a = 1

⇒ T
-2 = -b
b = 2
⇒ L
+1 = b + c
+1 = 2 + c
+1 - 2 = c
c = -1
Next Step Preview: Substituting a = 1, b = 2, c = -1 back into equation (i) yields:
F = (constant) m¹ v² r⁻¹ = m v² / r

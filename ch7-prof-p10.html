Harmonics & Organ Pipes
Rough Paper Draft · Discrete Frequencies · Air Columns
Harmonics :
Stationary waves follow Discrete (Different) set of frequencies:

f₁, 2f₁, 3f₁, 4f₁, ...

These frequencies are called Harmonics.
f₁ = 1st Harmonics or Fundamental frequency
f₂ = 2nd Harmonic
Board Check: "Here the 1 after the f is subscripted" (e.g., f₁ represents the base fundamental frequency).
Organ Pipe :
Organ Pipe (Air column) is a wind instruement that produces sound with the help of stationary waves. It has both ends open or it has one end open and the other closed.
Figure 1: Open from both sides (2 nodes, 3 antinodes)
Figure 2: One side open, other closed (3 nodes, 3 antinodes)
Imp note: Relation b/w incident wave and reflected wave depends on wether one end of the pipe is open or closed.
Side note:
fₙ = n f₁
n = 1 → f₁ = v/2l
n = 2 → f₂ = 2f₁
n = 3 → f₃ = 3f₁
n = 4 → f₄ = 4f₁

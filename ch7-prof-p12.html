2nd & Nth Modes of Vibration
Open Organ Pipe · Higher Harmonics Generalization
B — 2nd Mode of Vibration :
l = λ₂/4 + λ₂/2 + λ₂/4
★ Board note: In this Case, we have two nodes and three Anti-Nodes:
l = λ₂/4 + λ₂/2 + λ₂/4
l = (λ₂ + 2λ₂ + λ₂)/4 = 4λ₂/4 = λ₂
{ l = λ₂ }
Again:
v = f₂ λ₂
v / λ₂ = f₂
{ v / l = f₂ }  ∵ [λ₂ = l]
C — Nth Mode of Vibration :
In this Case:
{ λₙ = 2l / n }
{ fₙ = n·v / 2l }
n = 1, 2, 3, ...

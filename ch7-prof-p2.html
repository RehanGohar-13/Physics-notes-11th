Waves And Vibration (Chp #7)
Time Period, Frequency & Wave Velocity Equation
Cycle / Vibration:
It is one round trip (in a Time graph).
Time Period:
It is the time taken to complete a vibration (T).
Formula: T = 1 / f
Frequency:
It is the number of vibrations done in one second (f).
f = n / t
If n = 1, then: f = 1 / T
Wavelength:
It is the distance b/w 2 consecutive crest / trough (λ).
Velocity of Waves:

If a wave travels the distance of one wavelength (λ) in time (T):

Velocity = Distance / Time
V = λ / T = fλ    [∵ f = 1/T]

Result: v = fλ
